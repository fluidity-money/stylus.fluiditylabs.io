
# Stylus Tracker

Stylus Tracker is a simple webapp that provides a list of the Stylus contract deployments
across supported Arbitrum Stylus chains. It does so with an ingestor that polls a list of
RPCs at regular intervals, looking for events generated by the precompile. It aggregates
this list in a simple TSV that can be requested at any time.

Polling takes place once an hour. A new RPC endpoint can be added by making a pull request
and adding it to `chains.tsv`.
